# FinTrack Privacy Policy (Draft)

## ഞങ്ങൾ ശേഖരിക്കുന്ന data
- Google Authentication profile basics: name, email, photo URL.
- User-entered accounts, transactions, debts, EMI/bill schedules, notifications.

## Data ഉപയോഗിക്കുന്നത്
- Personal finance dashboard, reports, reminders, and backup/export features നൽകാൻ മാത്രം.

## Data sharing
- User data third-party advertisers-ക്ക് share ചെയ്യില്ല.
- Firebase services app infrastructure ആയി ഉപയോഗിക്കുന്നു.

## User controls
- CSV export and JSON backup download ചെയ്യാം.
- Backup import user action വഴി മാത്രം നടക്കും.
- Data deletion request support process production launch-ന് മുമ്പ് publish ചെയ്യണം.

## Security
- Firestore rules authenticated owner-only access enforce ചെയ്യാൻ തയ്യാറാക്കിയിട്ടുണ്ട്.
- Production-ൽ Firebase App Check enforce ചെയ്യണം.
