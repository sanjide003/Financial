# Data Retention Policy (Draft)

- Active user finance records user delete ചെയ്യുന്നതുവരെ retain ചെയ്യും.
- Notifications user clear ചെയ്യുന്നതുവരെ retain ചെയ്യും.
- Backup files browser download ആയി local device-ൽ സൂക്ഷിക്കും; app server-ൽ backup copy ഉണ്ടാക്കുന്നില്ല.
- Account deletion/data deletion workflow production support policy-ൽ define ചെയ്യണം.
